# BrainFuckInterpreter

Made with <3 by fluffy

## Usage

```
brainfuck <filename> <parameters>
```

### Possible Parameters

- `--use-special` will include the special featuers

## Special Features

- `:` Clone the current cell into the next one and go to it
- `;` Clone the current cell into the previous one and go to it
- `*` Multiply the cell by 2
- `/` Divide the cell by 2
